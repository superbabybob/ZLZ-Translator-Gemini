# 🌐 ZLZ-translator (Gemini-version)

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=flat&logo=python&logoColor=white)](https://www.python.org/)
[![AI Provider](https://img.shields.io/badge/AI-Google%20Gemini-4285F4?style=flat&logo=google)](https://aistudio.google.com/)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D6?style=flat&logo=windows)](https://microsoft.com)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**ZLZ-translator (Gemini-version)** คือเครื่องมือแปลภาษาและช่วยสื่อสารภาษาอังกฤษสำหรับฟรีแลนซ์และคนทำงานไทยที่ต้องคุยงานกับลูกค้าต่างชาติ ออกแบบมาให้ทำงานร่วมกับ **Discord** และ**ทุกโปรแกรมบน Windows** (เช่น Chrome, Slack, VS Code, LINE, Outlook) 

ประมวลผลผ่าน **Google Gemini API** (ตอบสนองเร็วเฉลี่ย ~1 วินาที และมีโควต้าฟรี 1,500 ครั้ง/วัน จาก Google AI Studio ไม่ต้องลงโปรแกรมหรือ CLI เสริม)

---

## ✨ จุดเด่นและความสามารถ

- ⚡ **เร็วระดับ 1 วินาที**: ขับเคลื่อนด้วย `gemini-2.5-flash` แปลและตอบกลับได้ทันท่วงที
- 🎁 **ฟรี & ไม่ผูกบัตร**: ใช้งานโควต้าฟรีจาก Google AI Studio ได้สูงสุด 1,500 ครั้ง/วัน
- ⌨️ **ปุ่มลัด Global Hotkeys**: กดใช้งานได้ในทุกแอปบน Windows ไม่จำกัดแค่ Discord
- 🔄 **พิมพ์ไทยกลายเป็นอังกฤษทันที (In-place Typing)**: พิมพ์ไทยในช่องแชท กด **F9** ข้อความจะแปลงเป็นอังกฤษในช่องเดิมทันที พร้อมกล่องข้อความเล็กๆ ตรวจทานความหมายก่อนที่คุณจะกดส่ง
- 🧠 **วิเคราะห์เจตนาลูกค้า (Intent Explanation)**: ลากคลุมข้อความอังกฤษ กด **Shift+F8** เพื่อดูสรุปความต้องการ ข้อตกลง และน้ำเสียงของลูกค้า
- 📝 **ปรับแก้ไวยากรณ์ (Grammar Polish)**: พิมพ์อังกฤษเองแล้วกด **Shift+F9** ให้ AI เกลาสำนวนให้เป็นมืออาชีพ
- 📚 **คลังศัพท์โปรเจกต์ (`glossary.md`)**: กำหนดคำศัพท์เฉพาะ ห้ามแปล หรือแนวทางน้ำเสียงได้เอง
- 🖥️ **มี GUI ตั้งค่าในตัว**: ขอคีย์ Gemini และตั้งปุ่มลัดใหม่ได้ง่ายๆ ผ่านเมนูโปรแกรม ไม่ต้องแก้โค้ด

## ⌨️ ปุ่มลัดหลัก (Hotkeys)

| ปุ่มลัด | ฟังก์ชัน | การทำงาน |
|:---:|---|---|
| **`F8`** | **แปลอังกฤษเป็นไทย** | ลากเมาส์คลุมข้อความภาษาอังกฤษของลูกค้า -> ป๊อปอัปจะแสดงคำแปลไทยทันที |
| **`F9`** | **ตอบกลับไทยเป็นอังกฤษ** | พิมพ์ภาษาไทยในช่องแชท -> ข้อความจะถูกแทนที่ด้วยภาษาอังกฤษ *(ยังไม่ส่ง เพื่อให้คุณตรวจทานก่อนกด Enter)* |
| **`Shift + F8`** | **วิเคราะห์เจตนาลูกค้า** | ลากคลุมข้อความอังกฤษ -> AI อธิบายเป็นไทยว่าลูกค้าหมายถึงอะไร ต้องการอะไร และน้ำเสียงเป็นอย่างไร |
| **`Shift + F9`** | **เกลาภาษาอังกฤษ** | พิมพ์อังกฤษในช่องแชท -> ปรับแก้ไวยากรณ์และรูปประโยคให้เป็นธรรมชาติระดับมืออาชีพ |

> 💡 ในหน้าต่างป๊อปอัปมีปุ่ม **คัดลอก (Copy)**, ตัวเลือกปรับน้ำเสียง (**ทางการ / เป็นกันเอง / สั้นกระชับ**) และปุ่ม **แปลกลับเช็ก (Back-translation)** เพื่อตรวจสอบว่าประโยคตรงตามที่ตั้งใจหรือไม่

## 🚀 เริ่มต้นใช้งานใน 3 นาที

### 1. ดาวน์โหลดโปรแกรม
- **แบบที่ 1 (ง่ายสุด)**: กดปุ่มเขียว **`Code`** ด้านบน แล้วเลือก [Download ZIP](https://github.com/superbabybob/ZLZ-Translator-Gemini/archive/refs/heads/main.zip) จากนั้นแตกไฟล์ลงในเครื่องของคุณ
- **แบบที่ 2 (ผ่าน Git)**:
  ```bash
  git clone https://github.com/superbabybob/ZLZ-Translator-Gemini.git
  ```

### 2. ติดตั้งในคลิกเดียว
- ดับเบิลคลิกไฟล์ **`setup.bat`** (หรือดับเบิลคลิก **`run_hotkey.bat`** ได้เลย ระบบจะติดตั้งให้อัตโนมัติในครั้งแรก)
- หากเครื่องของคุณยังไม่มี Python ตัวติดตั้งจะถามเพื่อติดตั้ง Python 3.12 ให้อัตโนมัติ
- เมื่อติดตั้งเสร็จ ตัวโปรแกรมจะสร้าง Shortcut **`ZLZ-translator (Gemini-version)`** ไว้บนหน้า Desktop ให้ทันที

### 3. ใส่ API Key ของ Gemini (ฟรี)
1. เมื่อเปิดโปรแกรม หากยังไม่พบคีย์ ระบบจะเปิดหน้าต่าง **"ตั้งค่าคีย์และบัญชี"** ขึ้นมาให้อัตโนมัติ
2. กดปุ่ม **"🌐 เปิดหน้าขอคีย์ Gemini"** (ล็อกอินบัญชี Google ที่ [Google AI Studio](https://aistudio.google.com/apikey))
3. กด **Create API key** คัดลอกคีย์มาวางในช่อง `GEMINI_API_KEY`
4. กด **บันทึกแล้วทดสอบแปล** เมื่อขึ้นข้อความสีเขียวว่าใช้ได้ เป็นอันเสร็จสิ้น!

## 🎛️ เมนูถาดระบบ (System Tray)

ไอคอนโปรแกรมจะอยู่ที่มุมขวาล่างของหน้าจอ (System Tray):
- **คลิกซ้าย**: เปิด/ปิดการทำงานชั่วคราว (สีน้ำเงิน = ปกติ, สีเทา = พักการทำงาน, สีส้ม = กำลังแปล)
- **คลิกขวา**: เปิดเมนูควบคุม
  - **ตั้งค่า: คีย์ / ปุ่มลัด / บัญชี...**: ปรับเปลี่ยนปุ่มลัดได้อิสระตามความถนัด
  - **น้ำเสียงตอนตอบ**: เลือกระดับภาษา (เป็นทางการ, เป็นกันเอง, สั้นกระชับ)
  - **เปิดอัตโนมัติเมื่อเข้า Windows**: ให้โปรแกรมเปิดพร้อมเครื่องคอมพิวเตอร์
  - **เปิดคลังศัพท์ (`glossary.md`)**: บันทึกคำศัพท์เฉพาะทาง
  - **เปิด/ปิด Discord App**: สลับสถานะบอท Discord (กรณีใช้งานเสริม)

## ⚙️ การปรับแต่งเพิ่มเติม

### 1. ปรับแต่งคำศัพท์เฉพาะทาง (`glossary.md`)
เปิดไฟล์ `glossary.md` เพื่อใส่บริบท เช่น:
- รายชื่อบุคคลและโปรเจกต์
- คำศัพท์เฉพาะวงการที่ไม่ต้องการให้แปลตรงตัว
- น้ำเสียงและลักษณะคำลงท้ายที่ชอบใช้

### 2. การตั้งค่าขั้นสูง (`config.toml`)
- สามารถเปลี่ยนโมเดล Gemini ได้ต่อโหมด (เช่น `gemini-2.5-flash` สำหรับความเร็ว หรือ `gemini-2.5-pro` สำหรับการวิเคราะห์เชิงลึก)
- กำหนดกลุ่มแอปที่อนุญาตให้ปุ่มลัดทำงาน (เช่น ให้ทำงานเฉพาะเมื่อเปิดหน้าต่าง Discord)

## 🤖 Discord User App (ฟังก์ชันเสริม)

นอกจากการใช้ปุ่มลัดบน Windows แล้ว คุณยังสามารถเปิดใช้งานโหมด **Discord User App** เพื่อคลิกขวาที่ข้อความใน Discord แล้วสั่งแปลได้ทันที (ใช้ได้กับทุกเซิร์ฟเวอร์และห้อง DM โดยไม่ต้องขอสิทธิ์ผู้ดูแลระบบ):

1. สร้างแอปที่ [Discord Developer Portal](https://discord.com/developers/applications)
2. ไปที่เมนู **Installation** -> เลือก **User Install** และเลือก Install Link เป็น **Discord Provided Link**
3. ไปที่เมนู **Bot** -> กด **Reset Token** แล้วนำ Token มาใส่ในโปรแกรม (ผ่านหน้าต่างตั้งค่าหรือในไฟล์ `.env` ช่อง `DISCORD_TOKEN`)
4. ติดตั้งแอปลงในบัญชี Discord ของคุณผ่านลิงก์ Install Link
5. สามารถคลิกขวาที่ข้อความใดๆ ใน Discord -> ไปที่เมนู **Apps** เพื่อสั่งแปลได้ทันที

## 🛠️ การแก้ไขปัญหาที่พบบ่อย (FAQ)

| ปัญหา | วิธีแก้ไข |
|---|---|
| **ปุ่มลัดไม่ทำงาน** | ตรวจสอบว่าโปรแกรมรันอยู่ (มีไอคอนสีน้ำเงินที่มุมขวาล่าง) และไอคอนไม่ได้เป็นสีเทา (หากเป็นสีเทาให้คลิกซ้าย 1 ครั้งเพื่อเปิด) |
| **ปุ่มลัดชนกับโปรแกรมอื่น** | คลิกขวาที่ไอคอน tray -> **ตั้งค่า: คีย์ / ปุ่มลัด / บัญชี...** แล้วกดปุ่มเพื่อบันทึกปุ่มลัดใหม่ที่ต้องการ |
| **F9 แทนที่ข้อความผิดช่อง** | ตรวจสอบให้แน่ใจว่าคลิกเคอร์เซอร์ลงในกล่องข้อความก่อนกด F9 |
| **ขึ้นข้อความแจ้งเตือนเรื่อง API Key** | ตรวจสอบว่าคัดลอก `GEMINI_API_KEY` มาครบถ้วน และอินเทอร์เน็ตสามารถเชื่อมต่อไปยัง `generativelanguage.googleapis.com` ได้ |
| **ต้องการดู Log การทำงาน** | ดูได้ที่ไฟล์ `data/hotkey.log` |
